# SOIS Homepage

Premium 925 sterling silver jewellery homepage built with **Next.js 15 (App Router)**.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command       | Description              |
|---------------|--------------------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build       |
| `npm run start` | Serve production build |

## Stack

- **Next.js 15** — App Router, Server Components, route-based code splitting
- **next/font** — Plus Jakarta Sans font optimization
- **next/image** — Optimized remote images (Unsplash)
- **TypeScript**

## SEO

- Metadata API (title, description, Open Graph, Twitter cards)
- `robots.ts` and `sitemap.ts`
- JSON-LD structured data (Organization, WebSite, Product list)
- Semantic HTML (`header`, `main`, `footer`, `nav`, `section`, `article`, `blockquote`)

## Responsive Breakpoints

- Mobile: 320px–767px (hamburger navigation)
- Tablet: 768px–1024px
- Desktop: 1025px+
